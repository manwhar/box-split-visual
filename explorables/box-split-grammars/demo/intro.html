Key Terms

What is a Box-Split Grammar

  • Grammar: A set of rules that breaks one big box into smaller pieces step by step. You can think about it like grammar in English that breaks a sentence into phrases and words.
  • Box-Split Grammar: Dr. Eger's nonterminal system that slices one big box into smaller pieces.
  • Nonterminal: A rule that expands further instead of placing blocks. For example, one side of a castle splits into tower(), wall(), gate(), wall(), and tower().
